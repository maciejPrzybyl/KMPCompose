This is a Kotlin Multiplatform project targeting Android, iOS, Web (WASM) and Desktop.\
It was made to verify current state of Kotlin Multiplatform ecosystem.\
Core functionalities:
- database (Android, iOS, Desktop)
- data storage (Android, iOS, Web, Desktop)
- background task (Android, iOS)
- push notifications (Android, iOS)
- maps (Android, iOS)
- sign in with Google (Android)
